How this works — and what we deliberately left out

Where the games run. Every button opens the game on the organisation that hosts it — mostly the Internet Archive's in-browser EM-DOSBox and JSMESS/Emularity emulators, ScummVM compiled to WebAssembly, or an official/open-source website. This site hosts no game files, ROMs, BIOS images or assets and takes no part in distributing them. When a host permits embedding, ▣ Here opens its player in a page overlay; otherwise the button simply opens the host in a new tab, clearly labelled with the host name. Some in-browser emulators need a moment to fetch the game, and a keyboard is required for DOS and arcade titles.

What counts as legitimate. The grid only includes official free releases (Minecraft Classic, Google's Pac-Man Doodle, Tetris), publisher-released shareware/freeware, open-source projects, and preservation copies the Internet Archive itself hosts under its own takedown policy. Unlicensed AAA web ports are excluded. Recent coverage of Skate 3, Black Ops Zombies, Simpsons Hit & Run, NFS Most Wanted and GTA browser builds describes projects that stream retail game assets from third-party servers; publishers have already issued DMCA takedowns for Black Ops II, GTA Vice City and others. Those are documented in the research table below, with no play buttons.

How this works

  • Own files — every port needs a copy of the original game you own; no game data lives here.
  • Project link — opens the community repo or the port announcement with the download and setup steps.
  • Platform badge — the console or arcade system the original game shipped on.
  • Cover art — the original box or key art for that game, used for identification only.

Before you download

  • Legality: dump the files from your own copy. These are unofficial fan projects, not re-releases.
  • Versions matter: some ports only accept one exact game version — read the linked page first.
  • Nothing is hosted here: this site is a bookmark list, not a download mirror or a launcher.
  • Community builds can be experimental; check requirements and back up your saves.
  • Links: every card link was checked on 2 Nov 2026; npm run links re-checks them.

“Can I skip owning the game?”

No — there is no legitimate workaround. These are decompilation and static recompilation projects: they rebuild the game's code, not its content. The art, audio, levels, textures and data stay with the publisher and are deliberately left out of every release.

Without those files the port has nothing to load, so it cannot start. You need to own the original game and dump the files from your own disc, cartridge or console. Downloading somebody else's copy is piracy; this directory does not host or link to game data.

What you can skip: the repeated setup. Most launchers read your dump once, build the PC version locally, and never need the disc again. That is a one-time step, not a way around ownership.
